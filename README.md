# Bank-Management-System  using Python
A simple Bank Management System using Python and JSON for account management and CRUD operations.

## Project Overview
This is a simple Bank Management System developed using Python. It allows users to create and manage bank accounts through a menu-driven program. Account information is stored in a JSON file.

## Features
- Create a new bank account
- Deposit money
- Withdraw money
- View account details
- Update account information
- Delete a bank account
- Generate a unique account number
- Store account data using JSON

## Technologies Used
- Python
- JSON
- Random Module
- String Module

## Project Structure

## How to Run
1. Download or clone this repository.
2. Make sure Python is installed.
3. Open the project folder in VS Code.
4. Run the following command:

```bash
python Main.py
```
